# V1 画图提示词（Claude / GPT 可直接复制）

> 使用方法：从下方选择一段提示词，直接粘贴给 Claude / GPT。
>
> 推荐输出格式：**SVG**（可保存为 `xxx.svg` 用浏览器打开）。

---

## 0. 全局提示词（强烈推荐先发这一段）

你是一名资深 UX / 产品设计师。请为“轻量技术创作社区（V1）”生成**低保真线框图**。

### 产品背景（必须遵守）

- 定位：面向泛技术爱好者的轻量技术创作社区
- 内容主线：先发布（草稿/发布）→ 再沉淀（摘要/标签/分区/精选）→ 再讨论（评论）
- 个人中心定位：创作管理台
- 审核：全局开关，开启时“发布”进入待审核

### 帖子状态（用中文提示即可）

- 草稿（仅作者可见）
- 待审核（作者/管理员可见）
- 已发布（所有人可见）
- 已拒绝（作者/管理员可见，作者可看拒绝原因）
- 已删除（仅管理员可见）

### 画图要求

- 输出：**仅输出 1 个完整 SVG 代码块**（不要解释，不要多余文字）
- 尺寸：1200×800（可滚动内容用“折叠区域/省略号”表达）
- 风格：低保真黑白灰；用矩形、线条、文本标注；不要上色，不要真实图片
- 字体：尽量使用中文（标题、按钮、提示文案用中文）
- 组件：每个组件用清晰的标题标注，例如“分区导航 / 热门标签 / 帖子卡片 / 评论区”等
- 交互：用小标注注明关键交互点（例如“Tab 切换 / 点击标签筛选 / 申请精选”）
- 登录态：如页面需要，可在右上角用“未登录/已登录”两种小区域表达

### 帖子卡片字段（首页列表必须出现）

- 标题、分区、摘要、作者、最近活动时间、浏览量、评论数

## 1. 首页（/）线框图提示词

在遵守“全局提示词”的前提下，为【首页】生成低保真线框图（SVG）。

### 页面结构

- 顶部导航：Logo、搜索框（可先留空/占位）、“发布”按钮、登录/用户入口
- 左侧：主分区导航（6 个：后端与开发实践、算法与竞赛、AI 与工具探索、解决方案与踩坑记录、工具与资源、茶水间）
- 中间：帖子列表区域
  - Tab1：最新发布（默认）
  - Tab2：精选方案
- 右侧：热门标签（可点击筛选），以及“我的创作入口/个人中心入口”

### 列表区细节

- 帖子卡片中必须展示：标题、分区、摘要（最多 2 行）、作者、最近活动时间、浏览量、评论数
- 列表顶部要有一个筛选条：当前分区、当前标签、排序方式（默认“按活跃”）

### 交互标注

- Tab 切换：最新发布/精选方案
- 点击分区筛选
- 点击标签筛选
- 点击帖子进入详情

## 2. 发帖页（/create-post）线框图提示词

在遵守“全局提示词”的前提下，为【发帖页】生成低保真线框图（SVG）。

### 表单字段

- 标题（必填）
- 分区（必填，下拉/选择）
- 标签（多选，支持输入+推荐）
- 摘要（可选，提示：不填将自动从正文提取，最多 300 字）
- 封面图（可选，上传区）
- 正文编辑器（Markdown/富文本占位即可）

### 关键按钮

- 左侧/下方：保存草稿
- 右侧/下方：发布帖子

### 状态提示

- 页面顶部或底部显示：自动保存状态（例如“已自动保存 12:01”）
- 如果是编辑已有草稿：显示当前状态“草稿”

---

## 3. 帖子详情页（/posts/:id）线框图提示词

在遵守“全局提示词”的前提下，为【帖子详情页】生成低保真线框图（SVG）。

### 页面模块

- 标题区：标题、分区、标签
- 作者区：作者头像/昵称、作者技术标签（徽章）、发布时间、最近活动时间
- 数据区：浏览量、评论数
- 正文区
- 评论区：评论输入框（登录后可用）、评论列表（分页/加载更多占位）

### 状态提示（仅作者/管理员可见）

- 如果状态为“待审核/已拒绝”：在正文上方显示状态条
- 已拒绝时显示“拒绝原因：xxxx”占位

## 4. 个人中心（/me）线框图提示词

在遵守“全局提示词”的前提下，为【个人中心】生成低保真线框图（SVG）。

### 页面结构

- 左侧：菜单（个人资料、我的帖子、我的足迹、账号设置）
- 右侧主区域：对应模块内容

### 我的帖子

- 顶部 Tab：草稿 / 待审核 / 已发布 / 已拒绝
- 每条帖子卡片展示：标题、分区、摘要、最近活动时间、浏览量、评论数
- 操作按钮（按状态显示）：
  - 草稿：编辑、删除、发布
  - 待审核：浏览、撤回
  - 已发布：浏览、编辑、删除、申请精选（已是精选则显示“取消精选”）
  - 已拒绝：浏览（含原因）、编辑、重新发布、删除

### 我的足迹

- 只展示浏览历史列表（标题、时间、来源分区）
- 明确标注“仅自己可见”

### 个人资料

- 头像、昵称、简介、所在地
- 技术标签（1~3 个徽章）支持编辑

### 账号设置
- 修改邮箱
- 修改密码
- 注销账号（需要二次确认）
- 退出登录

## 5. 作者公开主页（/users/:id）线框图提示词

在遵守“全局提示词”的前提下，为【作者公开主页】生成低保真线框图（SVG）。

### 页面内容

- 头像、昵称、简介
- 技术标签徽章（1~3 个）
- 已发布帖子列表（同首页卡片字段）

### 访问控制

- 不展示草稿/待审核/已拒绝
- 不展示“我的足迹”等私密模块

## 6. 管理后台（/admin）线框图提示词（可选）

在遵守“全局提示词”的前提下，为【管理后台】生成低保真线框图（SVG）。

### 页面目标

- 审核待审核帖子
- 审核精选申请
- 管理分区
- 管理用户（封禁、解封和查看用户帖子(主要用于审查用户删除的帖子)）

### 建议结构

- 左侧菜单：待审核帖子、精选申请、分区管理、用户管理
- 右侧：列表 + 详情抽屉/弹窗

### 审核弹窗关键点

- 审核通过按钮
- 审核拒绝按钮（拒绝原因必填）
