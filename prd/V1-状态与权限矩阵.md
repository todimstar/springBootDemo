# V1 状态与权限矩阵

## 1. 角色定义

- 游客：未登录用户
- 普通用户：已登录但不是帖子作者的用户
- 作者：帖子创建者本人
- 管理员：具有后台治理权限的用户

---

## 2. 帖子状态定义

- `0 DRAFT`：草稿
- `1 PENDING_REVIEW`：待审核
- `2 PUBLISHED`：已发布
- `3 REJECTED`：已拒绝
- `4 DELETED`：已删除

---

## 3. 可见性矩阵

| 帖子状态 | 游客 | 普通用户 | 作者 | 管理员 |
| --- | --- | --- | --- | --- |
| 草稿 DRAFT | 否 | 否 | 是 | 否 |
| 待审核 PENDING_REVIEW | 否 | 否 | 是 | 是 |
| 已发布 PUBLISHED | 是 | 是 | 是 | 是 |
| 已拒绝 REJECTED | 否 | 否 | 是 | 是 |
| 已删除 DELETED | 否 | 否 | 否 | 是 |

### 当前已实现规则映射

当前项目已确认：

- 非公开状态（如待审核、已拒绝）只有作者和管理员能看
- 软删除状态只有管理员能看
- 草稿仅作者可见（管理员不需要看到草稿）

该矩阵与现有规则保持一致。

---

## 4. 作者操作矩阵

| 帖子状态 | 浏览 | 编辑 | 删除 | 发布 | 撤回 | 申请精选 |
| --- | --- | --- | --- | --- | --- | --- |
| 草稿 DRAFT | 是 | 是 | 是 | 是 | 否 | 否 |
| 待审核 PENDING_REVIEW | 是 | 否 | 否 | 否 | 是 | 否 |
| 已发布 PUBLISHED | 是 | 是 | 是 | 否 | 否 | 是 |
| 已拒绝 REJECTED | 是 | 是 | 是 | 是 | 否 | 否 |
| 已删除 DELETED | 否 | 否 | 否 | 否 | 否 | 否 |

### 说明

- “发布”表示触发发布动作，而不代表一定直接公开
- 发布后的目标状态由审核开关决定
- “撤回”仅用于把待审核帖子撤回到草稿，可作为增强项

---

## 5. 管理员操作矩阵

| 帖子状态 | 浏览 | 审核通过 | 审核拒绝 | 删除 | 恢复 | 审核精选 |
| --- | --- | --- | --- | --- | --- | --- |
| 草稿 DRAFT | 否 | 否 | 否 | 否 | 否 | 否 |
| 待审核 PENDING_REVIEW | 是 | 是 | 是 | 否 | 否 | 否 |
| 已发布 PUBLISHED | 是 | 否 | 否 | 是 | 否 | 是 |
| 已拒绝 REJECTED | 是 | 否 | 否 | 是 | 否 | 否 |
| 已删除 DELETED | 是 | 否 | 否 | 否 | 是（可选） | 否 |

### 第一版建议保留的管理员能力

- 浏览帖子
- 审核通过
- 审核拒绝
- 分区管理
- 精选内容审核

### 第一版建议延后的能力

- 恢复已删除帖子
- 复杂用户管理
- 举报处理

---

## 6. 首页列表可见性规则

首页列表只展示：

- `PUBLISHED`

不展示：

- 草稿
- 待审核
- 已拒绝
- 已删除

### 排序规则

建议按 `last_activity_time DESC`。

---

## 7. 个人中心可见性规则

### 本人查看个人中心

可看到：

- 个人资料
- 我的帖子（全部状态，删除状态除外）
- 我的足迹

### 他人查看公开主页

仅可看到：

- 基础公开资料
- 技术标签
- 已发布帖子

不可看到：

- 我的足迹
- 草稿
- 待审核
- 已拒绝
- 私密统计

---

## 8. 发布动作规则

### 保存草稿

- 状态进入或保持 `DRAFT`

### 发布帖子

- `review.enabled = false` -> `PUBLISHED`
- `review.enabled = true` -> `PENDING_REVIEW`

### 重新发布被拒帖子

- 审核关闭：直接公开
- 审核开启：重新进入待审核

---

## 9. 精选申请规则

### 作者侧

- 仅已发布帖子可申请精选
- 申请入口放在个人中心“我的已发布帖子”列表中

### 管理员侧

- 审核是否进入精选列表

### 首页侧

- 精选方案页只展示“已发布且已通过精选审核”的帖子

---

## 10. 审核原因规则（建议）

### 拒绝原因

- 当管理员将帖子审核为 `REJECTED` 时，建议**必须填写拒绝原因**。
- 作者在个人中心的“已拒绝”列表中可查看拒绝原因。

### 删除原因

- V1 允许不实现“删除原因回传”。
- 若后续需要审计/追溯，建议用独立的“审核/治理日志表”记录管理员操作原因。
