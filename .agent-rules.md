# Project Rules for AI Agent

- Follow the existing code style and architecture of the project.
- Use TypeScript best practices if applicable.
- Prefer modern ES6+ syntax.

## Documentation Rule
- Always add JSDoc comments to new or undocumented functions. Ensure parameters and return types are clearly described.


## General
- Keep the code concise, elegant, professional, engineered, structured and reusable.
- Maintain the design concept and code in line with modern development standards.
- Do not read the documents in the "privateDoc" folder.


## Git Rule
- All submissions must be made outside the main branch. Submission and modification to the main branch are prohibited.
